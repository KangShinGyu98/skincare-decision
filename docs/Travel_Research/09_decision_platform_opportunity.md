# 결정 플랫폼 기회: Travel Decision Positioning

_Positioning definition document | Claude | 2026-08-19_

---

## 목적

현재 시장 안에서 이 아이디어가 차지할 포지션을 정의하고, 여행 의사결정 플랫폼으로서 갖춰야 할 핵심 기능과 여정 전환을 제안한다.

---

## 포지셔닝 맵

현재 시장은 대체로 아래와 같이 정리된다.

```
                        발견 / 영감 중심
                              ↑
      Instagram / YouTube     │     트리플 콘텐츠 / 마이리얼트립 큐레이션
      네이버 블로그 / 카페    │
                              │
정보 정리/기록  ←─────────────┼─────────────→  예약 / 커머스
 Wanderlog / Stippl / 노션    │     야놀자 / 여기어때 / 아고다
 트리플(중간 지점)            │     스카이스캐너 / 하나투어
                              │
                              ↓
                      조건 중심 / 결정 중심
                   [공백: Travel Decision Platform]
```

이 공백의 의미는 단순하다.

- 영감을 주는 곳은 많다.
- 예약을 받는 곳도 많다.
- 정리를 도와주는 곳도 있다.
- 일정 초안을 생성해 주는 AI도 이제 흔하다.
- 하지만 내 조건에서 `지금 무엇을 결정해야 하는지 줄여주는 곳`은 없다.

---

## 핵심 제품 개념

> "어디가 좋은지 보여주는 플랫폼이 아니라, 지금 내 조건에서 무엇을 결정하고 무엇은 미뤄도 되는지 알려주는 플랫폼."

이 개념의 핵심은 세 가지다.

1. 장소 추천보다 결정 순서 판단
2. 평점 평균보다 유사 여행자 증거
3. 일정 생성보다 일정 검증

---

## 핵심 기능 5개

### 1. Trip Priority Engine

조건(날짜·동행·예산·확정 상태)을 입력받아 지금 결정할 것, 미룰 것, 서둘러야 할 것을 이유와 함께 제시한다. 제품의 진입점이자 기반이다.

### 2. Decision Card

목적지·항공·숙소 지역·일별 일정이라는 결정 유형별로 판단 기준을 구조화한다. 목적지 카드와 항공 카드는 질문이 달라야 한다.

### 3. Reality Check

일정 초안을 이동시간·영업시간·휴무·체력(동행 보정) 기준으로 검증하고 수정안을 제시한다. AI 생성 일정의 검증 수요를 흡수한다.

### 4. Similar-Traveler Proof

후기를 동행 구성, 이동 방식, 여행 밀도, 시기에 연결해 평균 대신 `비슷한 조건의 결과`를 보여준다.

### 5. Trip Debrief

여행 후 계획 대비 실제와 실패 요인을 기록해 다음 여행의 Priority 판단 품질을 높인다. 저빈도 사용 문제를 데이터 누적으로 전환하는 장치다.

## 여정 전환

### 현재 여정

- 특가 알림이나 SNS에서 충동적으로 시작
- 블로그/유튜브/카페/구글맵/트리플/메타서치를 순회
- 결정 순서 없이 모든 판단을 동시에 떠안음
- 저장만 쌓이고 확정은 미뤄짐
- 다녀온 뒤 경험이 소실됨

### 제안 여정

1. 조건과 확정 상태 입력 (3분)
2. 지금 결정할 것과 결정 타임라인 확인
3. 해당 결정의 Decision Card로 기준 확인
4. 유사 여행자 증거로 후보 검증
5. 일정 초안을 Reality Check로 검증
6. 여행 후 Debrief 기록 → 다음 여행에 반영

핵심 전환은 `탐색`에서 `판단`으로, `동시에 전부`에서 `순서대로 하나씩`으로의 이동이다.

## 왜 지금 가능한가

### 1. AI 일정 생성의 범용화가 판단 수요를 만들었다

트리플 AI, 마이리얼트립 AI 플래너, ChatGPT가 초안 생성을 무료 표준으로 만들었다. 생성이 흔해질수록 "이 초안이 맞는가"라는 검증 질문의 가치가 커진다. 생성기와 싸우지 않고 생성기 위에 서는 타이밍이다.

### 2. 유사 조건 증거의 수요가 이미 언어화되었다

"아이랑", "부모님 모시고", "뚜벅이" 검색과, 트리플이 추천 사유에 동행 조건을 붙이기 시작한 것은 시장이 이 방향으로 움직인다는 신호다.

### 3. OTA 경쟁은 반대 방향으로 진화 중이다

야놀자·여기어때의 슈퍼앱 경쟁은 상품군 확장과 특가 경쟁이다. 판단 레이어는 예약 수수료 수익과 충돌하므로 그들이 채우기 어렵다.

## MVP 범위 제안

### 결정 유형 범위

초기에는 5개 결정 유형에 집중한다.

1. 목적지 확정 (조건 적합성 판단)
2. 항공 결정 (기준과 타이밍)
3. 숙소 지역 결정 (개별 숙소 이전 단계)
4. 일별 일정 구성 (Reality Check 포함)
5. 현지 재조정 (우선순위 태그 기반)

### 목적지 범위

초기에는 한국인 단기 해외여행의 최대 볼륨 지역 5곳에 집중한다.

1. 오사카
2. 도쿄
3. 후쿠오카
4. 다낭
5. 방콕

이 5곳은 3~5일 단기 여행 + 높은 재방문율 + 계획 정보 과잉이라는 공통점이 있어, 결정 피로가 가장 크고 데이터 시딩 효율이 가장 높다.

### 초기 사용자

- 트리플과 블로그·유튜브를 오가며 계획하는 자유여행자
- 동행의 계획을 떠맡은 `총무형` 사용자
- 저장은 수백 개인데 확정을 못 하는 사용자
- AI로 일정을 뽑아봤지만 믿지 못하는 사용자

## 핵심 시사점

1. 이 제품의 포지셔닝은 "더 똑똑한 트리플"이 아니라 "트리플과 OTA 진입 이전의 의사결정 레이어"다.
2. 핵심 차별화는 장소 데이터 양이 아니라 질문 구조다. 데이터는 적어도 판단이 정확하면 이긴다.
3. 성공 기준은 더 많은 장소를 보여주는 것이 아니라, 더 적은 결정으로 더 높은 확신을 주는 것이다.
