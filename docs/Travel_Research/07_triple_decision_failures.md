# 트리플의 결정 단계 실패: Triple Deep Dive

_Competitive deep dive document | Claude | 2026-08-19_

---

## 목적

트리플은 한국 자유여행 일정 관리의 기준점을 만든 서비스다. 뷰티 리서치에서 화해를 심층 분석했던 것과 같은 이유로 트리플을 분석한다. 기준점 서비스의 구조적 한계가 곧 다음 세대 제품이 풀어야 할 문제이기 때문이다. 이 문서는 트리플을 비난하기보다, 왜 그다음 단계의 제품이 필요해졌는지를 설명한다.

---

## 트리플이 만든 것

트리플은 `도시 선택 → 날짜 입력 → 장소 담기 → 날짜별 정리 → 지도에서 동선 확인`이라는 한국형 여행 계획 UX의 표준을 만들었다.

- 도시별 명소·맛집 데이터베이스와 저장 기능
- 날짜별 일정 보드와 지도 동선 시각화
- 동행과의 일정 공유·공동 편집
- 항공·숙소 예약 연결 (야놀자 그룹 통합 이후 강화)
- AI 일정 추천: 도시·날짜·여행 스타일을 고르면 일정 초안 생성
- AI 기반 개인화 홈: "내 일정에 담은 장소와 함께 많이 가는 곳", "아이와 여행할 때 가볼 만한 곳" 같은 추천 사유 표시

특히 추천에 `사유`를 붙이기 시작한 것과 동행 조건("아이와")을 추천에 반영하기 시작한 것은, 시장이 유사 조건 증거와 설명 가능성 방향으로 이동 중이라는 신호다.

---

## 그럼에도 남는 구조적 한계

### 1. 정리 도구이지 판단 도구가 아니다

트리플의 핵심 동사는 `담는다`와 `배치한다`다. 그러나 사용자의 진짜 어려움은 `무엇을 담을지 고르고, 담은 것 중 무엇을 버릴지` 결정하는 것이다. 그 결정은 여전히 블로그·유튜브·카페에서 일어나고, 트리플은 결정이 끝난 뒤에 등장한다.

### 2. 담기 전 단계(조건·순서)를 다루지 않는다

트리플의 시작은 "도시를 선택하세요"다. 즉 목적지 결정, 시기 판단, 항공·숙소 확정 순서라는 뼈대 결정(Stage 2~3)은 범위 밖이다. 사용자가 가장 크게 막히는 단계가 제품 진입 이전에 있다.

### 3. 추천이 인기 집계에 기반한다

"많이 담은 장소", "함께 많이 가는 곳"은 집계 신호다. 유명함과 내 조건 적합도의 혼동(랭킹 함정)을 해소하기보다 강화한다. 개인화 사유가 붙기 시작했지만, 아직 `왜 나에게`보다 `남들도`의 논리다.

### 4. AI 일정 추천은 초안을 주지만 검증과 근거가 없다

생성된 일정이 내 체력에서 실행 가능한지, 이동시간이 현실적인지, 왜 이 순서인지 설명하지 않는다. 초안의 그럴듯함이 오히려 검증 없이 실행하게 만드는 위험이 있다.

### 5. 예약 커머스 통합이 중립성을 제약한다

야놀자 그룹 통합 이후 트리플은 항공·숙소 최저가 예약을 전면에 내세운다. 예약 전환이 수익인 구조에서 "지금 예약하지 마라", "이 목적지는 네 조건에 안 맞는다" 같은 결론은 구조적으로 나오기 어렵다.

### 6. 일정의 현실성을 검증하지 않는다

장소를 아무리 많이 담아도, 하루에 8곳을 배치해도 경고가 없다. 지도에 동선이 그려질 뿐 그 동선이 무리라는 판단은 사용자 몫이다.

## 정리: 트리플이 답하는 질문과 답하지 못하는 질문

| 질문                                             | 트리플의 답변 능력 |
| ------------------------------------------------ | ------------------ |
| 담아둔 장소를 날짜별로 어떻게 정리하나           | 강함               |
| 동선이 지도에서 어떻게 보이나                    | 강함               |
| 동행과 일정을 어떻게 공유하나                    | 강함               |
| 이 도시에서 남들이 많이 가는 곳은 어디인가       | 강함               |
| 일정 초안을 빨리 만들 수 있나                    | 중간 (AI, 검증 없음) |
| 지금 무엇을 확정할 차례인가 (항공? 숙소? 일정?)  | 없음               |
| 이 시기·예산·동행에서 이 목적지가 맞는가         | 없음               |
| 이 일정이 내 체력과 동행에게 현실적인가          | 없음               |
| 나와 비슷한 조건의 여행자는 실제로 어땠는가      | 약함 (평점·집계 중심) |
| 지금 예약하는 게 합리적인가                      | 없음 (구조적 충돌)   |

## 화해와 트리플의 평행 구조

뷰티 리서치의 화해 분석과 정확히 같은 패턴이 관찰된다.

| 축                       | 화해 (뷰티)                        | 트리플 (여행)                      |
| ------------------------ | ---------------------------------- | ---------------------------------- |
| 만든 표준                | 성분·리뷰 기반 비교                | 일정 담기·정리 기반 계획           |
| 강한 단계                | 제품 선택 이후의 비교              | 장소 선택 이후의 정리              |
| 비어 있는 단계           | 카테고리 필요성 판단               | 조건 정의·뼈대 결정·순서 판단      |
| 수익 구조와의 충돌       | 리뷰와 브랜드 프로그램 병행        | 조언과 예약 커머스 병행            |
| 시장 신호                | Near-me Proof (유사 피부)          | 동행 조건 추천 사유 (아이와)       |

기준점 서비스는 자기 표준의 다음 단계를 스스로 만들기 어렵다. 수익 구조와 제품 정체성이 이미 굳어 있기 때문이다.

---

## 핵심 시사점

1. 트리플은 여행 계획의 `정리 표준`을 소유했지만, `판단 표준`은 아직 누구의 것도 아니다.
2. 트리플이 동행 조건 추천과 추천 사유를 붙이기 시작한 것은 판단 레이어 수요의 증거이며, 동시에 트리플이 그 방향으로 완전히 이동하기 어렵다는 것(커머스 통합)이 기회의 크기를 보여준다.
3. 새 제품의 포지션은 "더 좋은 트리플"이 아니라 "트리플 진입 이전의 결정 레이어"다. 일정 정리는 트리플에 맡겨도 된다.
