# Rule Research & Integration Plan (MVP)

목적: 유튜브/블로그 기반 루틴 정보를 서비스에 적용 가능한 Rule 형태로 변환하고, 공신력 있는 기준으로 검증 후 Product Matrix에 반영한다.

---

## 전체 전략

유튜브/블로그 → Rule 추출 → 구조화 → 검증 → 서비스 반영

---

## 작업 흐름

1. Rule 기반 자료 조사
2. Rule 구조화 (IF 조건 형태)
3. Attribute / Context / Rule로 분해
4. 공신력 기준으로 검증
5. Product Matrix에 반영

---

## 1. P0 — Rule 기반 자료 조사

목표: 실제 사용자들이 참고하는 콘텐츠에서 루틴/추천/주의사항을 수집한다.

예시:

- 건성 피부 - 닦는 토너 → 보습 성분 포함
- 지성 피부 - 닦는 토너 → 과도한 보습 피함
- 바르는 토너 → 수분 공급 목적

---

## 2. P1 — Rule 구조화 (핵심 단계)

목표: 모든 자료를 "조건 → 결과" 형태로 변환한다.

형식:
IF 조건
THEN 결과

예시:

Raw:
건성 피부 - 닦는 토너 - 보습 성분 포함

Parsed:
IF

- skin_type = dry
- toner_type = wiping

THEN

- hydration_level >= medium
- irritation_risk = low

---

## 3. P2 — 시스템 구조로 분해

목표: Rule을 3가지로 분리한다.

1. Attribute (제품)
2. Context (사용자)
3. Rule (판단)

예시:

원문:
닦는 토너 → 각질 정돈

Attribute:

- texture = water
- cleansing_effect = true

Context:

- skin_type = oily

Rule:
IF skin_type = oily
→ wiping_toner 우선

---

## 4. P3 — 공신력 기반 검증

목표: 사실만 검증하고 루틴은 참고로 사용한다.

검증 기준:

- 성분 효과 → 검증
- 유효 함량 → 검증
- 자극 성분 → 검증
- 피부 타입 추천 → 참고

예시:

- 나이아신아마이드 2~5% → 검증
- 지성 피부에 좋다 → 참고

---

## 5. P4 — Product Matrix 반영

목표: Rule을 실제 필터로 변환한다.

구조:
Context → Attribute 조건 → Filter

예시:
context.skin_type = dry
→ hydration_level >= medium
→ oiliness >= low

---

## 전체 흐름 요약

유튜브/블로그
→ Rule 추출
→ IF 형태로 변환
→ Attribute / Context / Rule 분리
→ 성분 검증
→ Filter 변환
→ Product Matrix 적용

---

## 작업 템플릿

Raw Rule:
(원문)

Parsed Rule:
IF

- 조건
  THEN
- 결과

Attribute Mapping:
(제품 속성)

Context Mapping:
(사용자 상태)

Filter Mapping:
(필터 조건)

- 자료를 그대로 쓰지 않는다
- 반드시 Rule 형태로 변환한다
- 성분만 객관적으로 검증한다
- 필터는 attribute 기반으로 만든다

## 1. Toner (토너)

### 사용 목적별 분류

**닦는 토너 (닦토)**

- 워터타입(가벼운 제형), 화장솜에 묻혀 사용
- 클렌징 후 잔여물 제거, 각질 정돈
- pH 밸런스 회복

**바르는 토너 (흡토)**

- 수분보충 목적, 점성 있는 제형
- 손 또는 화장솜으로 사용, 피부 보습 강화
- 다음 단계 스킨케어 흡수 도움

**결합형 (토너 패드)**

- 닦토 + 팩토 겸용
- 패드 형태로 휴대성 우수

### 피부타입별 선택 기준

**건성 피부**

- 닦는 토너: 보습 성분(히알루론산, 글리세린) 포함, 알코올 프리 선택, 자극 최소화
- 바르는 토너: 강력한 보습력, 세라마이드/판테놀 등 장벽 강화 성분
- 점성 있는 제형으로 막형성

**지성 피부**

- 닦는 토너: 티트리/어성초 등 진정 성분, 살리실산(BHA) 등 피지 조절
- 바르는 토너: 가벼운 제형, 끈적임 없는 산뜻한 보습
- 유수분 밸런싱 토너 권장

**복합성 피부**

- 계절/컨디션에 따라 닦토와 흡토 변경
- 여름/유분 많을 때: 산뜻한 수분 토너
- 겨울/예민할 때: 장벽 강화 토너
- T존은 닦토, U존은 흡토로 부분 사용 가능

**민감성 피부**

- 무알콜, 무향료 제품 선택
- 병풀/센텔라, 판테놀, 알로에 등 진정 성분
- 사용 빈도 조절(하루 1회 권장)
- 닦는 토너 사용 시 문지르지 말고 슥슥 닿게 사용

### 피부 고민별 선택 기준

| 고민       | 추천 성분                               |
| ---------- | --------------------------------------- |
| 각질       | AHA, BHA, PHA, 락틱산                   |
| 모공/피지  | 티트리, 살리실산, 하마멜리스, 어성초    |
| 미백/톤업  | 나이아신아마이드, 갈락토미세스, 비타민C |
| 진정       | 센텔라, 판테놀, 어성초, 알로에          |
| 안티에이징 | 항산화제(레스베라트롤, 제니스테인)      |
| 수분 부족  | 히알루론산, 베타인, 글리세린            |
| 장벽 강화  | 세라마이드, 판테놀                      |

### 피해야 할 성분

- 알코올 (건조 유발)
- 인공 향료, 색소 (민감 피부 자극)

## 2. Sunscreen (선크림)

### 차단 방식별 분류

**물리적 차단제 (무기자차)**

- 성분: 이산화티타늄, 징크옥사이드 (2가지뿐)
- 자외선을 반사
- 백탁 현상 있음, 발림성 떨어짐
- 피부 흡수되지 않아 자극 적음
- 추천: 민감성, 지성 피부, 어린이

**화학적 차단제 (유기자차)**

- 성분: 유기 화합물(아보벤존, 옥토크릴렌 등)
- 자외선을 흡수
- 백탁 없음, 발림성 우수
- 피부 흡수, 자극 가능성 있음
- 추천: 건성, 일반 피부

**혼합 차단제 (혼합자차)**

- 물리적 + 화학적 성분 모두 포함
- 균형 잡힌 사용감과 차단력
- 민감성 피부는 주의

### 자외선 차단 지수

**SPF (UVB 차단)**

- 일상 가벼운 외출: SPF 20-30
- 장시간 야외/실외 활동: SPF 30-50+
- 숫자가 높을수록 화학 성분 비율 증가

**PA (UVA 차단)**

- PA+: 외출 적을 때
- PA++: 가벼운 외출
- PA+++: 실외 활동 시 권장
- PA++++: 강한 자외선 노출 시

### 제형별 분류

| 제형            | 특징                   | 추천 피부    |
| --------------- | ---------------------- | ------------ |
| 선크림          | 표준 제형, 보습감      | 건성, 일반   |
| 선로션          | 묽은 제형, 가벼움      | 복합성       |
| 선밀크/플루이드 | 매우 묽음, 산뜻함      | 지성         |
| 선젤            | 점성 있는 젤, 산뜻     | 지성, 복합성 |
| 선스틱          | 휴대성 우수, 덧바르기  | 모든 타입    |
| 톤업 선크림     | 화이트닝 효과 추가     | 모든 타입    |
| 선스프레이      | 덧바르기 편함, 지속력↓ | 보조용       |

### 피부타입별 선택 기준

**건성 피부**

- 보습 성분 포함된 화학적 차단제
- 크림 타입 선호
- 히알루론산, 글리세린 함유 제품

**지성 피부**

- 무기자차(물리적 차단제) 권장
- 젤, 플루이드, 밀크 타입 (오일 프리)
- 끈적임 없는 산뜻한 사용감

**민감성 피부**

- 물리적 차단제만 사용 권장
- 무알콜, 무향료
- 혼합자차는 주의

**복합성 피부**

- 가벼운 제형의 혼합자차
- 또는 부위별 다른 제품 사용

## 3. Serum (세럼/에센스/앰플)

### 농도/제형별 차이 (참고용)

> 서비스에서는 통합 카테고리로 처리하되, 사용자 인식상 구분은 존재

| 구분   | 제형            | 농도      | 목적                     |
| ------ | --------------- | --------- | ------------------------ |
| 에센스 | 가장 묽음, 액체 | 낮음      | 수분 공급, 1차 보습      |
| 세럼   | 점성 있음       | 중간      | 특정 고민 집중 케어      |
| 앰플   | 가장 점성 높음  | 가장 높음 | 단기간 빠른 효과, 고기능 |

### 피부 고민별 선택 기준

**수분 부족/건조**

- 히알루론산 (저분자, 초저분자)
- 베타인, 판테놀
- 세라마이드, PDRN
- 추천 제형: 세럼 (점성 있는 제형이 보습력 우수)

**미백/잡티/톤업**

- 나이아신아마이드 (피부톤 정리, 미백)
- 비타민C, 비타민C 유도체
- 알부틴
- 갈락토미세스

**주름/탄력 (안티에이징)**

- 레티놀 (저자극부터 시작)
- 펩타이드 (EGF, 콜라겐 펩타이드)
- 아데노신
- 호박씨추출물, 레스베라트롤

**진정/트러블**

- 센텔라(병풀), 마데카소사이드
- 시카(CICA)
- 티트리
- 판테놀

**모공/피지**

- 살리실산(BHA)
- 나이아신아마이드
- PDRN

### 피부타입별 선택 기준

**건성 피부**

- 점성 높은 세럼/앰플 권장
- 보습 + 주름개선 기능 동시 추구
- 친수성 오일(호호바, 아르간) 함유

**지성/트러블 피부**

- 묽은 에센스 제형 선호
- 코코넛오일 회피 (트러블 유발)
- 미백세럼은 트러블 가라앉은 후 사용

**민감성 피부**

- 식물 추출물 기반 제품
- 인삼 배양 세포, 병풀 등 진정 성분
- 앰플은 자극 가능, 패치 테스트 필수

**일반/건강한 피부**

- 토너 + 크림만으로 충분
- 특정 고민이 없으면 생략 가능

### 사용 원칙

- 에센스/세럼/앰플 모두 함께 사용 불필요
- 피부 타입과 고민에 따라 1-2개만 선택
- 과한 영양 공급은 트러블 유발

## 4. Lipcare (립케어)

### 사용 목적별 분류

**립밤**

- 일상적 보습, 건조 예방
- 외출 전후, 수시 사용
- 스틱, 튜브, 단지 형태

**립마스크 / 립슬리핑마스크**

- 강력한 보습, 야간 집중 케어
- 두껍게 발라 슬리핑팩처럼 사용
- 각질 완화

**립에센스**

- 묽은 제형, 메이크업 전 베이스
- 흡수가 빠른 수분 공급

### 핵심 선택 기준

**보습제 + 폐쇄제 모두 포함된 제품 선택 (중요)**

- 보습제만 있으면 끌어온 수분이 증발하며 오히려 건조해짐
- 두 가지가 함께 있어야 장시간 보습 효과

| 성분 분류      | 역할           | 대표 성분                            |
| -------------- | -------------- | ------------------------------------ |
| 보습 성분      | 수분 공급      | 글리세린, 히알루론산, 알로에베라     |
| 폐쇄/장벽 성분 | 수분 증발 방지 | 시어버터, 비즈왁스, 바셀린, 스쿠알렌 |
| 회복 성분      | 손상 입술 케어 | 판테놀, 세라마이드                   |
| 영양 오일      | 부드러움 유지  | 호호바 오일, 아르간 오일             |

### 피해야 할 성분

| 성분                | 문제점                         |
| ------------------- | ------------------------------ |
| 멘톨, 페퍼민트 오일 | 쿨링감 있지만 입술 장벽 약화   |
| 살리실산, 캄파      | 각질 제거 성분, 얇은 입술 자극 |
| 향료, 색소          | 알레르기, 자극 유발            |
| 파라벤              | 알레르기 반응                  |
| 계피 (플럼핑 효과)  | 일시적 볼륨, 자극과 건조 유발  |

### 상황별 선택 기준

**입술이 자주 트는/심한 건조**

- 의약품(연고)성 립밤 (판테놀 5% 등)
- 라로슈포제, 바이오더마 등 약국 제품
- 시어버터, 세라마이드 함유 고보습 제품

**일상 사용**

- 무향, 무색소 저자극 제품
- 식물성 오일 + 폐쇄 성분 균형

**자외선 노출 시**

- 자외선 차단 기능 포함 립밤
- 입술은 멜라닌 적어 자외선에 취약

**립스틱 끼임 방지**

- 가벼운 발림성, 빠른 흡수 제품
- 메이크업 전용 베이스 립밤

### 추가 정보

- 색조 립 제품(립스틱, 틴트)은 카테고리 제외
- 립스크럽은 자극 가능, 자주 사용 비권장

## 5. Moisturizer (로션 / 크림)

### 제형별 분류

| 제형     | 특징                 | 수분/유분 비율       |
| -------- | -------------------- | -------------------- |
| 로션     | 묽은 액체, 빠른 흡수 | 수분 高 / 유분 低    |
| 젤크림   | 젤 형태, 산뜻        | 수분 高 / 유분 低    |
| 수분크림 | 가벼운 크림, 수분감  | 수분 中-高 / 유분 中 |
| 크림     | 되직, 영양감         | 수분 中 / 유분 高    |

### 핵심 선택 기준

**성분표 확인 (함량 순서대로 표기)**

- 물(Water/Aqua)이 첫 번째 → 수분 함량 높음
- 오일 성분이 앞에 → 유분 함량 높음

**보습제의 3가지 효과**

1. 밀폐 효과: 수분 증발 방지
2. 수분 효과: 피부에 수분 공급
3. 연화제 효과: 수분 침투 증가

### 피부타입별 선택 기준

**건성 피부**

- 크림 타입 권장 (밀폐 효과 강함)
- 세라마이드, 시어버터 함유 제품
- 로션 + 크림 레이어링 가능

**지성 피부**

- 로션 또는 젤크림 권장 (오일 프리)
- 가벼운 제형으로 모공 막힘 방지
- 로션만 사용해도 충분한 경우 많음

**복합성 피부**

- 가벼운 수분크림 또는 젤크림
- T존/U존 부위별 제형 조절 가능

**민감성 피부**

- 무향, 무색소, 무방부제 제품
- 향료/보존제로 인한 알레르기 접촉 피부염 주의
- 자극감(화끈, 따끔, 발적) 시 즉시 중단

### 계절별 권장

| 계절    | 추천 제형            |
| ------- | -------------------- |
| 여름    | 로션, 젤크림         |
| 봄/가을 | 수분크림             |
| 겨울    | 크림, 또는 로션+크림 |

### 사용 원칙

- 세안 후 3분 이내 도포 (효과적)
- 로션 → 크림 순서 (묽은 것부터)
- 손에 덜어 체온으로 녹인 뒤 사용
- 얼굴은 외부 자극 노출되므로 크림 형태 권장 (피부과 의견)

## 6. Cleanser (클렌저)

### 세정력 순서 (강 → 약)

> 클렌징오일 > 클렌징밤 > 클렌징크림 > 클렌징젤 > 클렌징폼 > 클렌징워터

세정력이 강할수록 자극도 비례하여 증가

### 제형별 분류

**클렌징 워터**

- 정제수 베이스, 미셀라 기술
- 자극 가장 적음, 세정력 가장 약함
- 화장솜에 적셔 닦아내듯 사용
- 추천: 민감성, 건성, 노메이크업, 가벼운 베이스
- 워터프루프 메이크업은 어려움

**클렌징 젤**

- 약산성(pH 5.0-6.5) 설계 가능
- 수용성, 산뜻한 사용감
- 모공 잔유감 적음
- 추천: 지성, 복합성, 트러블 피부
- 아침 세안에도 적합

**클렌징 폼**

- 거품으로 세정, 풍성한 거품
- 자극 비교적 적음
- 가벼운 메이크업 제거에 적합
- 모든 피부 타입 사용 가능

**클렌징 로션 / 밀크**

- 보습제 함량 높음, 가벼운 제형
- 부드러운 사용감
- 추천: 건성, 노화, 민감, 여드름 피부
- 가벼운 메이크업 제거용

**클렌징 크림**

- 진한 메이크업 제거
- 체온에 녹아 부드럽게 마사지
- 사용 후 2차 세안 필수
- 추천: 건성, 일반 피부

**클렌징 밤**

- 고체 제형, 컨트롤 쉬움
- 피부에 닿으면 오일로 변환
- 워터프루프 마스카라 등 강한 메이크업 제거
- 추천: 중성-건성, 풀메이크업 사용자

**클렌징 오일**

- 세정력 가장 강함
- 진한 메이크업, 피지, 기름기 제거
- 강한 자극, 2차 폼 세안 필수
- 추천: 건성, 노화 피부
- 비추천: 지성, 여드름 피부

### 피부타입별 선택 기준

**건성 피부**

- 자극 적은 제품, 비누 세안 금지
- 클렌징 밀크, 로션, 크림, 오일 권장
- 거품 클렌저 사용 시 충분히 거품 내어 사용

**지성 피부**

- 오일 프리 제품 (워터, 젤 권장)
- pH 4.5-5.5 약산성 제품
- 크림 타입 회피
- 모공 정화: 글리콜릭산, 살리실산 함유

**복합성 피부**

- T존: 지성 타입 클렌저
- U존: 건성 타입 클렌저
- 또는 균형 잡힌 젤 타입

**민감성 피부**

- 천연 성분 함유, 저자극 계면활성제
- 비누 사용 금지
- 거품 충분히 내어 사용
- 아침은 물 세안만 권장

### 메이크업 강도별 선택

| 메이크업 정도            | 권장 클렌저                  |
| ------------------------ | ---------------------------- |
| 노메이크업/베이스만      | 클렌징 워터, 폼              |
| 가벼운 메이크업          | 클렌징 젤, 로션              |
| 일반 메이크업            | 클렌징 밀크, 크림, 밤        |
| 진한 메이크업/워터프루프 | 클렌징 오일, 밤 (+ 2차 세안) |

### 이중 세안 원칙

- 메이크업 + 선크림 사용 시 권장
- 1차: 오일/밤/크림 (유성 노폐물 제거)
- 2차: 폼/젤 (수성 노폐물 제거)
- 과도한 세안은 피부 장벽 손상

## 종합: Attribute로 추출 가능한 항목

서비스 내부 로직에서 사용할 수 있는 attribute 후보:

**공통 attributes**

- `skin_type`: 건성 / 지성 / 복합성 / 민감성 / 일반
- `skin_concern`: 수분부족 / 모공 / 트러블 / 미백 / 주름 / 진정 / 각질
- `texture`: 워터 / 젤 / 로션 / 크림 / 밤 / 오일 / 스틱
- `is_alcohol_free`: bool
- `is_fragrance_free`: bool
- `season`: 봄 / 여름 / 가을 / 겨울

**카테고리별 특화 attributes**

| 카테고리    | 특화 속성                                               |

| serum       | concentration (에센스/세럼/앰플), target_concern        |
| lipcare     | has_humectant, has_occlusive, has_spf                   |
| moisturizer | water_oil_ratio, viscosity                              |
| cleanser    | cleansing_power, ph_level, formulation                  |
