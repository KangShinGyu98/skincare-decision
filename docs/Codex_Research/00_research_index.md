## 1. 서비스 현황 분석

**파일:** `01_service_breakdown.md`  
**성격:** 시장 지도 작성 (Market Mapping)

### 분석 요약

K-Beauty 의사결정과 관련된 서비스를 6개 유형으로 분류했다.

- **커머스/발견형:** 올리브영, YesStyle, Amazon, Sephora. 구매 전환과 탐색에 강하지만 "지금 내게 맞는가"보다 판매와 발견에 최적화되어 있다.
- **리뷰/성분형:** 화해, 글로우픽. 성분과 리뷰를 한데 모으지만 여전히 제품 단위 평가가 중심이다.
- **성분 해독형:** INCIDecoder, COSDNA, SkinSort. 원료 이해에는 강하지만 루틴 우선순위나 실제 사용 적합도는 약하다.
- **진단/개인화형:** Olive Young Skin Scan, Perfect Corp, Revieve. 개인화 인터페이스는 제공하지만 대개 판매 보조 도구다.
- **UGC/트렌드형:** TikTok, Instagram, YouTube. 발견 속도는 빠르지만 광고 혼재와 정보 편차가 크다.
- **전문가/의료형:** 피부과, AAD 같은 전문 가이드. 신뢰도는 높지만 실시간 제품 선택 워크플로와 연결되지 않는다.

**핵심 결론:** 현재 시장은 "무엇이 인기인가"와 "어떤 성분이 들어 있는가"는 잘 답하지만, "지금 내 루틴에서 무엇이 우선인가"는 아무도 충분히 답하지 못한다.

## 2. 공통 패턴 분석

**파일:** `02_common_patterns.md`  
**성격:** 횡단 비교 분석 (Cross-Platform Pattern Analysis)

### 분석 요약

플랫폼을 가로지르는 6가지 공통 패턴을 정리했다.

1. **랭킹/리뷰가 기본 인터페이스다.** 거의 모든 서비스가 베스트/어워즈/상위 리뷰로 시작한다.
2. **성분 언어는 보편화되었지만 해석 능력은 고르지 않다.** 성분을 본다고 해서 포뮬러 적합도를 이해하는 것은 아니다.
3. **커머스와 조언이 강하게 얽혀 있다.** 판매와 중립적 상담이 같은 인터페이스에 공존한다.
4. **유사 사용자 증거의 가치가 상승 중이다.** "나와 비슷한 피부"의 후기가 점점 더 중요해진다.
5. **카테고리별 의사결정 언어가 다르다.** 선크림은 스펙, 세럼은 성분과 내성, 립밤은 자극과 사용감 중심이다.
6. **트렌드는 빨라졌지만 루틴 우선순위는 더 흐려졌다.** PDRN, 레티날, 토너패드 같은 트렌드가 구매를 자극하지만 기본 루틴과의 관계는 덜 설명된다.

**핵심 결론:** 현재 시장은 하나의 통합 점수나 랭킹으로는 설명할 수 없는 카테고리별 차이를 가지고 있는데, 대부분의 플랫폼은 이를 충분히 반영하지 못한다.

## 3. 사용자 행동 패턴

**파일:** `03_user_behavior_patterns.md`  
**성격:** 사용자 리서치 (User Behavior Research)

### 분석 요약

화장품 선택 행동은 단일 검색이 아니라 다채널 검증 과정으로 나타난다.

- **트렌드 추종형:** TikTok·릴스·인스타로 신제품을 발견하고 올리브영/화해에서 검증한다.
- **성분 집착형:** 화해, INCIDecoder, 유튜브 성분 설명을 돌며 "문제 성분"을 먼저 거른다.
- **루틴 최적화형:** 세럼 하나보다 클렌징, 보습, 선케어의 우선순위를 따진다.
- **실용 최소화형:** 제품 수를 줄이고 싶어 하며 "이 카테고리 자체가 필요한지"를 묻는다.

사용자는 보통 한 플랫폼을 신뢰하지 않고, 성분 확인 → 리뷰 확인 → 유사 피부 후기 확인 → 오프라인 테스트까지 이동한다. 이 행동은 충성도 부족이 아니라, 어떤 플랫폼도 충분한 결정을 대신 내려주지 못하기 때문에 발생하는 워크어라운드다.

## 4. 기존 플랫폼의 한계

**파일:** `04_problems_and_limitations.md`  
**성격:** 문제 정의 (Problem Definition)

### 분석 요약

현재 뷰티 플랫폼의 핵심 한계는 기능 부족이 아니라 구조적 질문의 오류에 있다.

- **올리브영:** 구매 데이터와 리뷰는 풍부하지만 본질적으로 커머스 최적화 시스템이다.
- **화해:** 성분·리뷰·랭킹의 기준점을 제공했지만 제품 단위 비교에 머무르기 쉽다.
- **트렌드 플랫폼:** 빠른 발견은 가능하지만 광고/협찬/과장 메시지와 뒤섞인다.
- **성분 DB:** 원료를 해독해도 내 피부, 현재 루틴, 사용 순서의 문제는 남는다.
- **AI 진단 도구:** 흥미로운 진입점이지만 독립적 의사결정자라기보다 판매 전환 인터페이스에 가깝다.

**구조적 문제 5개:**

- 랭킹 함정: 인기와 적합도가 섞인다.
- 성분 환원주의: 한 성분이 전부를 설명하는 것처럼 소비된다.
- 카테고리 블라인드니스: "어떤 제품"보다 먼저 "어떤 종류가 필요한가"가 빠져 있다.
- 루틴 블라인드니스: 제품이 루틴 안에서 평가되지 않는다.
- 신뢰 파편화: 리뷰, 광고, 체험단, 인플루언서가 한 흐름에 섞인다.

## 5. 시장 기회 분석

**파일:** `05_market_opportunities.md`  
**성격:** 기회 발굴 (Opportunity Identification)

### 분석 요약

시장 기회는 "더 정확한 추천"이 아니라 "더 적은 선택"을 주는 데 있다.

1. **Need-before-product 엔진:** 제품 추천 전에 이 카테고리가 정말 필요한지부터 판단.
2. **카테고리별 의사결정 카드:** 선크림, 클렌저, 세럼, 립밤의 선택 기준을 분리.
3. **Routine Priority Engine:** 사용자의 현재 루틴에서 가장 영향력이 큰 다음 선택을 제안.
4. **Similar-Skin Proof:** 피부 타입, 고민, 자극 경험이 비슷한 사용자 데이터 우선.
5. **독립형 의사결정 레이어:** 커머스/광고와 분리된 기준점.

## 6. 화장품 선택 결정 여정

**파일:** `06_decision_stage_journey.md`  
**성격:** 사용자 여정 매핑 (User Journey Mapping)

### 분석 요약

사용자의 실제 질문은 "이 제품 좋나?"보다 복잡하다.

1. 지금 내 고민의 우선순위는 무엇인가
2. 제품이 아니라 루틴을 먼저 바꿔야 하는가
3. 이 카테고리에서 어떤 기준이 중요한가
4. 내 피부/루틴에서 문제를 일으키지 않는가
5. 나와 비슷한 사람이 실제로 만족했는가

현재 사용자는 이 질문을 해결하기 위해 화해, 올리브영, 유튜브, SNS, 커뮤니티, 성분 앱을 순회한다.

## 7. 화해의 결정 단계 실패

**파일:** `07_hwahae_decision_failures.md`  
**성격:** 경쟁 분석 심층 연구 (Competitive Deep Dive)

### 분석 요약

화해는 한국 뷰티 의사결정의 기준점을 만들었지만, "이 제품이 지금 내게 맞는가"라는 질문에는 구조적으로 한계가 있다.

- 제품 선택 이후의 비교에는 강하지만, 카테고리 필요성 자체는 잘 다루지 못한다.
- 성분 정보는 풍부하지만 포뮬러 맥락과 루틴 맥락은 제한적이다.
- 유사 피부 후기의 가치를 인정하지만 여전히 제품 단위 탐색 흐름이 중심이다.
- 리뷰와 브랜드 프로그램을 동시에 운영하는 구조는 의사결정 레이어의 독립성을 약하게 만든다.

이 문서는 화해를 비난하기보다, 왜 다음 단계의 제품이 필요해졌는지를 설명한다.

## 8. 충족되지 않은 결정 니즈

**파일:** `08_unmet_decision_needs.md`  
**성격:** 니즈 발굴 심층 분석 (Unmet Needs Deep Dive)

### 분석 요약

현재 플랫폼이 충분히 해결하지 못하는 9가지 니즈를 정리했다.

1. 지금 이 카테고리가 필요한가
2. 이 카테고리에서 꼭 봐야 할 1~2개 기준은 무엇인가
3. 내 피부/루틴에서 피해야 할 조합은 무엇인가
4. 나와 비슷한 피부의 실패 패턴은 무엇인가
5. 어떤 제품 때문에 뒤집어졌는지 어떻게 역추적할 것인가
6. 효과보다 자극/불편 가능성은 어떤가
7. 트렌드 제품인가, 기본기 제품인가
8. 이 제품 대신 루틴/생활 습관을 먼저 바꿔야 하는가
9. 신뢰할 수 있는 채널과 정품 위험은 어떤가

이 니즈를 바탕으로 `Routine Priority Card`, `Product Fit Card`, `Reaction Traceback` 개념을 제안했다.

## 9. 결정 플랫폼 기회

**파일:** `09_decision_platform_opportunity.md`  
**성격:** 포지셔닝 정의 (Positioning Definition)

### 분석 요약

시장 포지셔닝의 핵심은 `트렌드/발견`과 `구매/커머스` 사이가 아니라, `루틴 중심의 독립적 결정`에 있다.

핵심 기능은 5가지다.

1. Routine Priority Engine
2. Category Decision Card
3. Product Fit Card
4. Similar-Skin Review Graph
5. Adaptation Tracker

핵심 전환은 "랭킹을 더 잘 보여주는 서비스"가 아니라 "불필요한 구매를 줄여주는 서비스"다.

**파일:** `11_product_strategy.md`

## 12. 제품 방향 평가

**파일:** `12_product_direction_evaluation.md`  
**성격:** 방향성 검증 및 기능 평가 (Direction Evaluation & Feature Scoring)

### 분석 요약

초기 아이디어였던 트렌드 인사이트, AI 피부 진단, 랭킹 통합, 루틴 우선순위 엔진 등을 비교 평가했다. 결론은 다음과 같다.

- **트렌드 인사이트:** 유입용 보조 레이어로는 좋지만 핵심 MVP는 아님
- **AI 피부 셀피 진단:** 장기 옵션, 초기 핵심 아님
- **범용 랭킹 통합:** 즉시 폐기
- **루틴 우선순위 엔진 + 카테고리 카드:** 핵심

## 13. 핵심 기능 정의 & 실행 계획

**파일:** `13_core_features_and_execution_plan.md`  
**성격:** 기능 설계 + 실행 계획 (Feature Design & Implementation Plan)

### 분석 요약

핵심 기능을 3레이어 구조로 정의했다.

```
Layer 3: Guidance
Routine Priority Engine / Adaptation Tracker / Reaction Traceback

Layer 2: Decision Objects
Category Decision Card / Product Fit Card / Similar-Skin Reviews

Layer 1: Context
Skin Profile / Routine Baseline / Constraints
```

초기 실행은 6개 카테고리 시딩, 구조화 데이터 수집, 유사 피부 리뷰 신호 설계, 수익모델 가드레일 설정 순으로 제안했다.
