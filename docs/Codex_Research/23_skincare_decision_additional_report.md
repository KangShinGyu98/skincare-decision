## 1. 이 문서의 목적

기존 산출물인 `docs/db_modeling.md`, `docs/wireframe_summary.md`, `Codex_Research/18_summary.md`, `21_decision_flow_revision.md`, `22_wireframe.md`는

다만 실제 서비스 설계 관점에서 아직 비어 있는 부분은 아래 4가지다.

1. **실제 스킨케어 루틴의 우선순위가 더 명시적으로 정리되어야 한다**
2. **체크리스트를 어떤 질문 묶음으로 구성할지 더 구체화되어야 한다**
3. **제품군보다 한 단계 더 아래인 제형(formulation / format) 판단 기준이 필요하다**
4. **정보 탐색 사이트와 실제 구매 사이트를 어떻게 분리·연결할지 정리되어야 한다**

이 문서는 바로 그 공백을 메우기 위한 추가 보고서다.

## 2. 뷰티 구매 여정 자료가 말해주는 것

`89-DIGITAL-iNSIGHT-2026-04-29.txt`와 폴더 내부 이미지 OCR 결과를 종합하면, 뷰티/스킨케어 구매 여정은 제품 상세 페이지보다 훨씬 앞 단계에서 이미 대부분의 판단이 이뤄진다.

### 핵심 관찰

- 초기 탐색 + 정보 탐색 단계에 검색 활동의 **약 89%**가 집중된다
- 이미지 OCR 기준 단계 비중은 대략 아래와 같다
  - 초기 탐색: **45.5%**
  - 정보 탐색: **43.5%**
  - 경험 탐색: **5.2%**
  - 구매 확정: **2.4%**
  - 구매 이후: **3.4%**
- 즉 사용자는 구매 직전보다 **그 전에 무엇을 사야 하는지, 무엇을 피해야 하는지, 어떤 기준으로 봐야 하는지**를 더 오래 탐색한다

### 도메인 역할 정리

이미지/텍스트 자료와 기존 리서치를 함께 보면 한국 시장에서 도메인 역할은 비교적 선명하다.

| 도메인        | 주 역할                                           | 우리 서비스에서의 의미                        |
| ------------- | ------------------------------------------------- | --------------------------------------------- |
| 네이버        | 범용 검색 허브, 키워드 탐색, 블로그/커뮤니티 연결 | 유입 키워드 설계, 검색형 랜딩 진입점          |
| 올리브영      | 리뷰 + 대중적 구매 + 오프라인 테스트              | 제품 DB 링크 우선 채널, 대중 SKU 기준점       |
| 무신사 뷰티   | 트렌드 발견, 라이징 브랜드, 감도 높은 큐레이션    | 발견/탐색 레이어 참고, 젊은 층 탐색 언어 참고 |
| 쿠팡          | 구매 실행, 가격/세트/빠른 배송 탐색               | 실행 채널 보조 링크                           |
| 브랜드 공식몰 | 정품/라인 설명/프로모션/샘플                      | 성분표·라인 맥락·공식 구매 경로               |
| 화해          | 성분/리뷰/피부타입 필터                           | 독립 정보 검증 레이어                         |

### 이 자료가 주는 설계 결론

우리 서비스의 핵심은 단순 추천이 아니라 아래 순서여야 한다.

1. **지금 뭘 먼저 고쳐야 하는지 판단**
2. **그 카테고리에서 뭘 봐야 하는지 번역**
3. **제품 후보를 줄여줌**
4. **마지막에만 구매 채널로 넘김**

즉, 제품 카드보다 **체크리스트와 판단 언어**가 먼저다.

## 3. 현재 설계에서 보강이 필요한 실제 루틴 관점

현재 문서들은 선크림, 세럼, 립케어에 대한 구조는 비교적 명확하다.  
하지만 실제 스킨케어 루틴은 아래 5개 축이 더 기본이다.

1. 클렌저
2. 보습제
3. 선크림
4. 기능성 세럼/앰플
5. 립케어

특히 `02_common_patterns.md`, `03_user_behavior_patterns.md`, `11_product_strategy.md`에서 반복적으로 확인되는 점은 다음과 같다.

- 선크림, 세럼, 립밤은 **같은 언어로 비교하면 안 된다**
- 사용자는 종종 세럼/앰플/패드/립마스크를 찾고 있지만 실제로 필요한 것은 **클렌저·보습제·선크림 같은 기초 루틴 안정화**일 수 있다
- 반복 사용 카테고리에서는 효능보다도 **사용감, 휴대성, 덧바르기 쉬움, 밀림 여부, 당김 여부**가 실제 재구매를 좌우한다

즉 MVP 제품군 우선순위는 아래처럼 보는 것이 맞다.

### MVP 우선 제품군

| 우선순위 | 제품군    | 이유                                                           |
| -------- | --------- | -------------------------------------------------------------- |
| 1        | 클렌저    | 메이크업/선크림 사용과 직접 연결, 과세정/불충분 세정 모두 문제 |
| 2        | 보습제    | 장벽/당김/민감/베이스 밀림과 직접 연결                         |
| 3        | 선크림    | 주간 루틴과 색소/노화/외출 맥락에서 핵심                       |
| 4        | 세럼/앰플 | 관심은 높지만 루틴 안정화 이후에 들어가야 정확도가 올라감      |
| 5        | 립케어    | 반복 사용성이 높고 향료/멘톨/보호막 언어가 분명함              |

### Phase 2 제품군

- 토너/스킨
- 토너패드
- 스팟/트러블 케어
- 필링/AHA/BHA
- 마스크팩

이들은 수요는 크지만, 루틴 우선순위 판단의 핵심축은 아니다.

## 4. 체크리스트는 어떻게 구성해야 하는가

기존 문서의 방향대로, 체크리스트는 길고 진단형 설문이 아니라 **짧은 구매 전 게이트 + 카테고리별 세부 기준**의 2단 구조가 적합하다.

## 4-1. Layer A: 공통 Priority Gate

목적은 `지금 제품을 사야 하나`보다 정확히는 아래 두 가지다.

1. **루틴이 비어 있는지**
2. **루틴이 불안정한지**

### A. 루틴 공백 체크

| 질문                                      | 입력 방식           | 왜 중요한가                     | 결과                    |
| ----------------------------------------- | ------------------- | ------------------------------- | ----------------------- |
| 클렌저를 매일 쓰나요?                     | 매일 / 가끔 / 안 씀 | 선크림/메이크업 루틴의 기본     | 안 씀이면 클렌저 우선   |
| 보습제를 매일 쓰나요?                     | 매일 / 가끔 / 안 씀 | 장벽/당김/민감과 직결           | 안 씀이면 보습제 우선   |
| 선크림을 거의 매일 쓰나요?                | 매일 / 가끔 / 안 씀 | 주간 외출/색소/노화 고민과 직결 | 조건부로 선크림 우선    |
| 현재 세럼/앰플 같은 기능성 제품을 쓰나요? | 다중 선택           | 루틴 과밀도 판단                | 많으면 신규 액티브 보류 |

### B. 루틴 불안정 체크

| 질문                                           | 입력 방식 | 왜 중요한가                    | 결과                        |
| ---------------------------------------------- | --------- | ------------------------------ | --------------------------- |
| 최근 7일 내 따가움/붉어짐/가려움이 반복됐나요? | 예/아니오 | 신규 액티브 도입 보류 판단     | 자극군 HOLD                 |
| 최근 2주 내 새 제품을 2개 이상 추가했나요?     | 예/아니오 | 원인 분리 불가 상태            | 루틴 고정 권고              |
| 세안 후 당김/건조/따가움이 자주 있나요?        | 예/아니오 | 과세정/장벽 약화 가능성        | 보습/클렌저 우선            |
| 강한 액티브, 필링, 홈케어를 최근에 했나요?     | 예/아니오 | 자극 누적 가능성               | 세럼/필링 HOLD              |
| 선크림/메이크업 후 세정이 잘 안 되는 편인가요? | 예/아니오 | 잔여물/트러블/과세정 모두 연결 | 클렌저 재점검               |
| 최근 수면/스트레스/식습관 변화가 컸나요?       | 예/아니오 | 루틴 외부 변수 확인            | 결과 문구에서 불확실성 안내 |

### C. 조건부 핵심 문항

`21_decision_flow_revision.md`의 지적대로 선크림 질문은 매우 중요하지만 모든 사용자에게 동일 비중으로 던지면 선크림 편향적으로 보일 수 있다.

따라서 아래처럼 나누는 것이 좋다.

- 공통 문항: `기본 보호/보습 루틴이 안정적이다`
- 조건부 문항: `야외 활동이 많다 / 색소·노화 고민이다 / 아침 루틴 제품을 찾는다`일 때 `선크림 사용 안정성` 추가

즉 선크림은 **전역 핵심 문항이 아니라 조건부 핵심 문항**이다.

## 4-2. Layer B: 카테고리별 Decision Checklist

Priority Gate를 통과한 뒤에는 카테고리별 질문이 달라져야 한다.  
핵심은 `피부 타입을 무조건 묻는 것`이 아니라 `그 제품군에서 실제로 실패를 줄이는 질문만 묻는 것`이다.

### 1. 클렌저

**이 카테고리의 실제 질문**

- 선크림/메이크업을 지워야 하는가
- 세정 후 당김이 심한가
- 이중세안을 감수할 수 있는가
- 오일/밤/젤/폼 중 어떤 제형이 덜 불편한가
- 아침용/저녁용이 같은가 다른가

**핵심 체크 기준**

| 기준            | 설명                                     |
| --------------- | ---------------------------------------- |
| 세정 강도       | 메이크업/워터프루프 선크림 기준 충분한가 |
| 사용 후 당김    | 충분히 씻기되 과하게 뺏지 않는가         |
| 이중세안 필요성 | 오일/밤 사용 허용 여부                   |
| 제형 선호       | 오일, 밤, 젤, 폼, 크림                   |
| 향/자극 회피    | 민감 사용자의 이탈 포인트                |

### 2. 보습제

**이 카테고리의 실제 질문**

- 세안 후 당김이 반복되는가
- 아침 화장 전에 밀리지 않아야 하는가
- 낮에는 가볍게, 밤에는 보호막 중심이 필요한가
- 유분감/답답함이 싫은가
- 장벽 보완 목적이 큰가

**핵심 체크 기준**

| 기준               | 설명                              |
| ------------------ | --------------------------------- |
| 제형 무게감        | 젤, 로션, 크림, 밤                |
| 장벽 보완          | 보호막/지속력 중심인지            |
| 밀림 여부          | 메이크업 전 사용 적합성           |
| 계절/시간대 적합성 | 여름/겨울, 아침/밤                |
| 트러블 부담        | 무겁고 답답한 제형 회피 필요 여부 |

### 3. 선크림

**이 카테고리의 실제 질문**

- 야외 활동이 많은가
- 눈시림이 있는가
- 백탁이 불편한가
- 메이크업 위에 써야 하는가
- 덧바르기 쉬운 형태가 필요한가
- 휴대용인가 집용인가

**핵심 체크 기준**

| 기준          | 설명                     |
| ------------- | ------------------------ |
| SPF/PA        | 기본 스펙                |
| 필터 타입     | 무기자차/유기자차/혼합   |
| 눈시림        | 개인화 필터의 핵심       |
| 백탁          | 사용 중단의 주요 이유    |
| 재도포 편의   | 스틱/쿠션/소형 튜브 여부 |
| 메이크업 궁합 | 밀림/들뜸 여부           |

### 4. 세럼/앰플

**이 카테고리의 실제 질문**

- 무엇을 해결하고 싶은가
- 최근 자극이 있었는가
- 현재 쓰는 액티브와 충돌하는가
- 아침용인가 밤용인가
- 빠른 체감 vs 느리지만 안정적인 변화를 원하는가
- 선크림 루틴이 이미 안정적인가

**핵심 체크 기준**

| 기준           | 설명                                   |
| -------------- | -------------------------------------- |
| 목적 성분      | 미백/진정/탄력/각질/트러블             |
| 자극 가능성    | 저/중/고                               |
| 병행 주의      | 레티노이드, 비타민C, AHA/BHA 등        |
| 사용 시간대    | morning / night / both                 |
| 기대 시차      | 빠른 체감 vs 완만한 변화               |
| 루틴 선행 조건 | 선크림/보습 루틴이 안정적이어야 하는가 |

### 5. 립케어

**이 카테고리의 실제 질문**

- 갈라짐/벗겨짐이 반복되는가
- 향료나 멘톨에 불편감이 있는가
- 실외용이라 SPF가 필요한가
- 자주 덧바르기 어려운가
- 스틱/튜브/팟/슬리핑 마스크 중 무엇이 편한가

**핵심 체크 기준**

| 기준           | 설명                    |
| -------------- | ----------------------- |
| 자극 성분 회피 | 향료, 멘톨, 화한 사용감 |
| 보호막 형성    | occlusive 중심인지      |
| SPF 여부       | 야외 사용 시 중요       |
| 휴대성         | 스틱/튜브 선호 여부     |
| 반복 사용 편의 | 자주 꺼내 바르기 쉬운가 |

---

## 5. 룰은 어떻게 선정해야 하는가

룰은 많이 만드는 것이 목표가 아니다.  
사용자의 실패를 줄이는 데 직접 연결되는 룰만 남겨야 한다.

가장 좋은 구조는 **Hard Rule → Route Rule → Fit Rule** 3층 구조다.

## 5-1. Hard Rule

이 단계는 `지금 사지 말아야 할 것` 또는 `지금 추가하면 안 되는 것`을 먼저 잡는다.

### 권장 Hard Rule 세트

1. **최근 자극 반복**
   - 조건: 최근 따가움/붉어짐/가려움 반복
   - 결과: 신규 세럼, 필링, 강한 액티브 HOLD

2. **최근 다수의 신제품 추가**
   - 조건: 최근 2주 내 신제품 2개 이상
   - 결과: 루틴 7~14일 고정 권고

3. **세안 후 당김 + 보습 루틴 부재**
   - 조건: 세안 후 당김 있음 + 보습제 미사용/불규칙
   - 결과: 세럼보다 보습제 우선

4. **선크림/메이크업 사용 + 세정 불안정**
   - 조건: 선크림/메이크업 자주 사용 + 세정 불안정
   - 결과: 클렌저 우선 재정비

5. **색소/노화 고민 + 선크림 불안정**
   - 조건: 관련 고민 + 선크림 미정착
   - 결과: 기능성 세럼보다 선크림 우선

6. **입술 갈라짐 반복 + 향료/멘톨 민감**
   - 조건: 갈라짐 반복 + 자극 사용감 민감
   - 결과: 향 없는 보호막형 립케어 우선, 틴티드/향 립류 보류

## 5-2. Route Rule

이 단계는 `어느 제품군으로 보내야 하는가`를 결정한다.

### 권장 Route Rule 세트

| 조건                            | 우선 라우팅 |
| ------------------------------- | ----------- |
| 클렌저 미사용 또는 세정 불만    | 클렌저      |
| 보습제 미사용 + 건조/당김 반복  | 보습제      |
| 야외 활동 많음 + 선크림 미정착  | 선크림      |
| 기본 루틴 안정 + 특정 고민 명확 | 세럼/앰플   |
| 입술 갈라짐/벗겨짐 반복         | 립케어      |

## 5-3. Fit Rule

이 단계는 제품군 내부에서 후보를 줄이는 규칙이다.

### 권장 Fit Rule 예시

| 카테고리 | 조건                | 필터 결과                       |
| -------- | ------------------- | ------------------------------- |
| 선크림   | 눈시림 경험 있음    | `eye_sting = none/low` 우선     |
| 선크림   | 백탁 민감           | `white_cast = none/low` 우선    |
| 선크림   | 외출/휴대 필요      | 스틱/소형 튜브/가벼운 제형 우선 |
| 보습제   | 메이크업 전 사용    | 로션/젤크림/밀림 적은 제형 우선 |
| 보습제   | 밤 루틴 + 건조 심함 | 크림/밤 타입 우선               |
| 세럼     | 레티노이드 사용 중  | 산성/자극 액티브 중복 후보 주의 |
| 세럼     | 최근 자극 있음      | 저자극/진정/장벽 계열 우선      |
| 립케어   | 멘톨 민감           | 멘톨/쿨링 성분 제외             |
| 립케어   | 야외 사용           | SPF 포함 후보 태그              |

## 7. 어떤 사이트에서 구할 수 있게 설계해야 하는가

사용자는 적합도를 확인한 다음 다시 다른 앱에서 가격과 정품 여부를 확인한다.  
이 분절을 줄이는 것이 중요하다. 다만 우리 서비스는 커머스화되지 않도록 **판단 레이어와 구매 레이어를 분리**해야 한다.

## 7-1. 사이트 역할 분리

| 역할           | 사이트                                       | 서비스 안에서의 위치       |
| -------------- | -------------------------------------------- | -------------------------- |
| 정보 탐색      | 네이버, 블로그, 커뮤니티, 유튜브/인스타/틱톡 | 유입 키워드와 진입 콘텐츠  |
| 리뷰/성분 검증 | 화해, 올리브영 리뷰                          | 후보 검증 보조 신호        |
| 대중 구매 채널 | 올리브영, 쿠팡                               | 구매 링크 영역             |
| 트렌드 발견    | 무신사 뷰티                                  | 발견형 보조 채널           |
| 공식 기준점    | 브랜드 공식몰                                | 정품/라인 맥락/공식 이벤트 |

## 7-2. 제품 상세 화면의 구매 링크 구조

구매 링크는 1개가 아니라 아래처럼 다중 구조가 좋다.

1. **공식몰**
   - 정품/라인 설명/샘플/번들 확인
2. **올리브영**
   - 대중성, 리뷰, 오프라인 테스트 가능성
3. **쿠팡**
   - 가격/빠른 배송/세트
4. **무신사 뷰티**
   - 해당 브랜드가 입점된 경우 트렌드 맥락 보조

중요한 점은 구매 링크를 제품 적합도 바로 아래에 섞지 않는 것이다.

- 상단: 적합/주의/회피 이유
- 중단: 제품 속성, 제형, 유사 피부 근거
- 하단 분리 블록: 구매 가능한 채널

즉 `왜 이 제품이 맞는가`를 먼저 보여주고, `어디서 살 수 있는가`는 나중에 보여줘야 한다.

## 7-3. DB 차원의 채널 모델 제안

현재 문서에서는 `구매 링크`가 단일 필드처럼 보인다.  
실제 운영에서는 아래처럼 별도 테이블이 더 맞다.

### 제안 테이블: `product_purchase_links`

| 컬럼         | 설명                                                  |
| ------------ | ----------------------------------------------------- |
| id           | PK                                                    |
| product_id   | 제품 연결                                             |
| channel_type | `official`, `oliveyoung`, `coupang`, `musinsa`, `etc` |
| url          | 구매 링크                                             |
| seller_name  | 판매처 표시명                                         |
| is_official  | 공식 판매처 여부                                      |
| price        | 현재 가격 또는 기준 가격                              |
| price_tier   | 가격대                                                |
| note         | 오늘드림, 세트, 한정, 쿠폰 등                         |
| is_active    | 노출 여부                                             |

이 구조가 있어야 사용자가 `적합도 판단`과 `실제 구매 실행`을 한 흐름 안에서 끝낼 수 있다.

## 8-3. Priority Rule 설계 원칙

룰은 많아지면 복잡해지므로 아래 순서를 고정하는 것이 좋다.

1. 자극/불안정성 HOLD 룰
2. 루틴 공백 라우팅 룰
3. 카테고리 선택 룰
4. 개인화 필터 룰
5. 채널/가격 노출 룰

이 순서가 뒤바뀌면 다시 “추천은 많은데 지금 뭘 해야 하는지 모르겠는” 상태로 돌아간다.

## 9. 최종 제안

이 프로젝트의 추가 리서치는 더 많은 SKU를 모으는 것보다 먼저 아래를 고정하는 쪽이 맞다.

### 먼저 고정할 것

1. **루틴 우선순위**
   - 클렌저 → 보습제 → 선크림 → 세럼/앰플 → 립케어

2. **체크리스트 구조**
   - 공통 Priority Gate
   - 카테고리별 Decision Checklist
   - 제품 후보 필터링
   - 구매 채널 분리 노출

3. **제형 체계**
   - 같은 제품군 안에서도 form이 의사결정 핵심 변수임을 명시

4. **채널 체계**
   - 정보 탐색, 검증, 구매 실행 사이트를 분리해 설계

### 나중에 확장할 것

- 토너패드, 마스크팩, 스팟케어 등 서브 카테고리
- 유사 피부군 성공/실패 통계
- 채널별 실시간 가격/재고 동기화
- 구매 후 적응 추적 자동화
