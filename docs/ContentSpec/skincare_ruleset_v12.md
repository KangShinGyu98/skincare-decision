# 스킨케어 결정 룰셋 v12 — Seed-Ready Rules

> 카테고리 5개(토너·썬크림·세럼·모이스처라이저·클렌저), 립케어는 범위 밖.
> 모든 룰은 **행동 카드 1장**에 대응한다. 카드는 `title`(질문-답변 맥락 확인) + `description`(행동 안내) + 선택적 `CTA`로 구성된다.
> v11 대비 변경: ① 개선 목적(노화·미백) 성분 추천 룰에서 `Q-U1 안씀 EXCLUDED` 조건을 제거해, 썬크림 미사용자도 "썬크림이 먼저예요" 카드와 "성분 추천" 카드를 함께 받도록 수정 ② sort_order를 010 단위로 전체 재정렬(구간별 재시작).

## 0. 설계 규약

### 0.1 구현 제약 (`priority-gate.service.ts` 기준)

- 조건은 `question_id | operator | value[] | state` 형태만 가능하다. 파생값·계산 필드는 없다.
- 사용 가능한 operator: `EQ` `NEQ` `IN` `CONTAINS` `GTE` `LTE`
- `state`는 `REQUIRED`(모두 충족=AND) 또는 `EXCLUDED`(하나라도 맞으면 룰 탈락=NOT)
- **결과 카드는 매칭된 룰을 전부 노출**한다. `sort_order`는 노출 순서만 결정한다.
- 미응답 시 `REQUIRED`는 실패(룰 차단), `EXCLUDED`는 통과.
- **필수 응답 질문: `Q-D1`·`Q-D5`·`Q-R3`** (티어 판정 입력 — §1 표에 ★로 표기).

### 0.2 연산자 매핑

| 의미 | 구현 |
| --- | --- |
| 다중선택에 특정 값이 있음 | `CONTAINS [x]` + REQUIRED |
| 다중선택에 여러 값 중 하나라도 있음 | `IN [a,b,c]` + REQUIRED |
| 특정 값이 없음 | `CONTAINS [x]` + EXCLUDED |
| 여러 값 중 아무것도 없음 | `IN [a,b,c]` + EXCLUDED |

- 다중선택 질문의 "없음"·"해당 없음" 값은 조건식에서 참조하지 않는다.
- **`GTE`/`LTE`는 선택지 배열의 인덱스(0-based)를 비교한다.**

### 0.3 티어 — 조건 매크로

**`[T1아님]`** = `Q-D1 IN [의료항목] (EXCLUDED)` + `Q-D5 IN [치료항목] (EXCLUDED)`
**`[T2]`** = `[T1아님]` + `Q-R3 EQ [있음] (REQUIRED)` — 장벽 민감
**`[T3]`** = `[T1아님]` + `Q-R3 EQ [없음] (REQUIRED)` — 장벽 멀쩡

T1 자체를 트리거로 쓰는 룰(10·20)은 각 조건의 별도 룰로 분리한다.

### 0.4 상호배타 원칙

같은 상황에서 두 룰이 함께 발동해 메시지가 중복되면, 한쪽에 `EXCLUDED` 조건을 넣어 하나만 발동하게 한다. **단, 정보성 안내(순서·전제 고지)와 실행 안내(성분 추천)는 배타 대상이 아니다** — 서로 다른 질문에 답하는 카드라 함께 나가야 한다(§4 원칙 참고, 이번 개정 사유).

### 0.5 티어별 가능 범위 (문서용 — 룰 아님)

| 티어 | 할 수 있는 것 |
| --- | --- |
| **T1 치료 수준** | 의료 안내 우선. 화장품은 보습·자외선차단·세안까지만 |
| **T2 장벽 민감** | 액티브 불가. 기초 루틴 점검 + 저농도 나이아신아마이드까지 |
| **T3 장벽 멀쩡** | 액티브 및 루틴 개선 가능 |

### 0.6 성분별 자극 프로파일 (참조표 — 룰 아님)

| 성분 | 자극 시 처리 | 이유 |
| --- | --- | --- |
| 레티노이드 / 비타민C / AHA·BHA / 모름·기타 | **HOLD** | 턴오버 촉진·저pH·각질제거 등으로 장벽 손상 악화 위험, 미상 성분은 안전 우선 |
| 나이아신아마이드 | 주의 | 10%↑ 고농도·미적응 시 따끔거림·홍조 가능 |
| 아젤라익 | 주의 | 15~20% 초반 사용 시 따끔거림·홍조 흔함, 저농도·적응자는 유지 가능 |
| 트라넥삼산 / 펩타이드·아데노신 / PDRN·콜라겐·글루타치온 | 유지 가능 | 저자극·재생 계열 |
| 마데카소사이드·센텔라 | 유지 권장 | 진정·장벽회복 목적이라 오히려 필요 |

### 0.7 팁 모음 (룰 아님, 조건 없이 정보로만)
- 기본 루틴 순서: 클렌징 → 토너(선택) → 보습제 → 썬크림
- 샤워 순서: 머리 먼저·세안 마지막

- 배갯잇·수건 위생, 브러시 세척 주기

## 4. 판정 원칙 (룰 아님 — 내부 규약)

- 티어는 조건 매크로일 뿐 카드가 되지 않는다. 중단·전환 안내는 **실제로 그 제품을 쓰고 있을 때만** 발동한다.
- 피부타입 라벨을 만들지 않고 당김(Q-R4)·번들거림(Q-R5) 원시값을 직접 참조한다.
- 토너는 필수가 아니다 — 당김이 없거나 이미 쓰고 있으면 관여하지 않는다.
- 보습제는 당김이 있을 때만 개입한다.
- 이미 사용 중인 성분은 추천에서 제외한다(EXCLUDED).
- `Q-C2 EQ 모름`은 알칼리성과 동일하게 취급한다.
- 다중선택의 "없음" 값은 조건식에서 참조하지 않는다.
- **상호배타는 "같은 질문에 다른 답을 주는 카드끼리"만 적용한다.** 정보성 고지(예: 610 "썬크림이 먼저예요")와 실행 안내(예: 620 "레티노이드를 이렇게 쓰세요")는 서로 다른 질문에 답하므로 배타 대상이 아니며 함께 노출한다(v12 개정).
- title은 질문-답변 맥락을 되짚는 문장으로, description은 행동 안내로 쓴다.
