# 스킨케어 결정 룰셋 v10 — Seed-Ready Rules

> 카테고리 5개(토너·썬크림·세럼·모이스처라이저·클렌저), 립케어는 범위 밖.
> 모든 룰은 **행동 카드 1장**에 대응한다. 개념적 상태(티어)는 조건으로만 쓰이고 그 자체로 카드가 되지 않는다.

---

## 0. 설계 규약

### 0.1 구현 제약 (`priority-gate.service.ts` 기준)

- 조건은 `question_id | operator | value[] | state` 형태만 가능하다. 파생값·계산 필드는 없다.
- 사용 가능한 operator: `EQ` `NEQ` `IN` `CONTAINS` `GTE` `LTE`
- `state`는 `REQUIRED`(모두 충족=AND) 또는 `EXCLUDED`(하나라도 맞으면 룰 탈락=NOT)
- **결과 카드는 최대 3장**이므로 `sort_order`가 노출 우선순위를 결정한다.
- 미응답 시 `REQUIRED`는 실패(룰 차단), `EXCLUDED`는 통과. → Q-D1·Q-D5·Q-R3는 필수 응답으로 다뤄야 안전하다.

### 0.2 연산자 매핑

| 의미 | 구현 |
| --- | --- |
| 다중선택에 특정 값이 있음 | `CONTAINS [x]` + REQUIRED |
| 다중선택에 여러 값 중 하나라도 있음 | `IN [a,b,c]` + REQUIRED |
| 특정 값이 없음 | `CONTAINS [x]` + EXCLUDED |
| 여러 값 중 아무것도 없음 | `IN [a,b,c]` + EXCLUDED |

다중선택 질문의 "없음"·"해당 없음" 값은 조건식에서 참조하지 않는다. 없음 상태는 실제 항목의 부재(EXCLUDED)로 판정한다.

### 0.3 티어 — 조건 매크로

티어는 DB 컬럼이 아니라 **조건 묶음의 축약 표기**다. seed 생성 시 아래대로 전개한다.

**`[T1아님]`** — 치료 수준이 아님 (2줄)

| question | operator | value | state |
| --- | --- | --- | --- |
| Q-D1 | IN | [심한여드름, 흉터, 사마귀, 주사, 아토피] | EXCLUDED |
| Q-D5 | IN | [처방치료, 미용시술, 약국약] | EXCLUDED |

**`[T2]`** — 장벽 민감 (3줄) = `[T1아님]` + 아래

| question | operator | value | state |
| --- | --- | --- | --- |
| Q-R3 | EQ | [있음] | REQUIRED |

**`[T3]`** — 장벽 멀쩡 (3줄) = `[T1아님]` + 아래

| question | operator | value | state |
| --- | --- | --- | --- |
| Q-R3 | EQ | [없음] | REQUIRED |

> `T1 = A OR B`는 OR라서 단일 룰로 표현할 수 없지만, 실제로 필요한 건 `NOT T1`이고 드모르간으로 `NOT A AND NOT B`가 되므로 EXCLUDED 2줄로 표현된다. T1 자체를 트리거로 쓰는 룰(의료 라우팅·치료 중 안내)은 각각 A, B를 트리거로 하는 별도 룰로 분리한다.

### 0.4 상호배타 원칙

같은 상황에서 두 룰이 함께 발동해 메시지가 중복되면, 한쪽에 `EXCLUDED` 조건을 넣어 항상 하나만 발동하게 한다.

### 0.5 티어별 가능 범위 (문서용 — 룰 아님)

| 티어 | 할 수 있는 것 |
| --- | --- |
| **T1 치료 수준** | 의료 안내 우선. 화장품은 보습·자외선차단·세안까지만 |
| **T2 장벽 민감** | 액티브 불가. 기초 루틴 점검 + 저농도 나이아신아마이드까지 |
| **T3 장벽 멀쩡** | 액티브 및 루틴 개선 가능 |

### 0.6 팁 모음 (룰 아님, 조건 없이 정보로만)
- 기본 루틴 순서: 클렌징 → 토너(선택) → 보습제 → 썬크림
- 샤워 순서: 머리 먼저·세안 마지막
- 세안 baseline: 미지근한 물 / 손 먼저 씻기 / 하루 2회 기준
- 배갯잇·수건 위생, 브러시 세척 주기

## 2. Rule Check 조건식 테이블 (seed-ready)

### 2.1 성분별 자극 프로파일 (참조표 — 룰 아님)

자극 상태(T2)에서 세럼 활성 성분을 어떻게 처리할지의 근거다. **유지 가능 성분에는 어떤 안내도 내보내지 않는다.**

| 성분 | 자극 시 처리 | 이유 |
| --- | --- | --- |
| 레티노이드 | **HOLD** | 턴오버 강제 촉진 → 장벽 손상 상태에서 악화 위험 큼 |
| 비타민C | **HOLD** | 저pH·산화 자극 있는 제형 많음(특히 아스코르빅애씨드) |
| AHA/BHA | **HOLD** | 각질제거 성분 자체가 장벽을 얇게 만듦 |
| 모름·기타 | **HOLD** | 성분 미상은 리스크 판단 불가 → 안전 우선 |
| 나이아신아마이드 | 주의 | 대체로 장벽 강화에 도움되지만 10% 이상 고농도이거나 적응 전이면 따끔거림·홍조 가능 |
| 아젤라익 | 주의 | 사용 초반(특히 15~20% 고농도) 따끔거림·홍조 흔함. 저농도(<10%)·적응된 사용자는 유지 가능 |
| 트라넥삼산 | 유지 가능 | 자극 거의 없음, 진정 계열에 가까움 |
| 펩타이드·아데노신 | 유지 가능 | 분자 자체가 순한 편, 저자극 |
| PDRN·콜라겐·글루타치온 | 유지 가능 | 재생·보습 계열, 자극 케이스 드묾 |
| 마데카소사이드·센텔라 | 유지 권장 | 진정·장벽회복 목적 성분이라 이 상태에 오히려 필요 |

## 4. 판정 원칙 (룰 아님 — 내부 규약)

- 티어는 조건 매크로일 뿐이며 그 자체로 카드가 되지 않는다. "액티브를 멈추세요" 같은 안내는 **실제로 그 제품을 쓰고 있을 때만** 발동해야 하므로, 반드시 보유·사용 질문(Q-S2·Q-T1·Q-C3 등)과 결합한다.
- 피부타입 라벨을 만들지 않고 당김(Q-R4)·번들거림(Q-R5) 원시값을 직접 참조한다.
- 토너는 필수가 아니다 — 당김이 없거나 이미 쓰고 있으면 관여하지 않는다.
- 보습제는 당김이 있을 때만 개입한다.
- 이미 사용 중인 성분은 추천에서 제외한다(EXCLUDED).
- `Q-C2 EQ 모름`은 알칼리성과 동일하게 취급한다.
- 다중선택의 "없음" 값은 조건식에서 참조하지 않는다.
- 조건이 겹치는 룰은 EXCLUDED로 상호배타 처리한다.

## 5. 보류

- 모공 개선 — 각질·피지 항목과 성분이 중복되어 별도 축으로 두지 않음
- 등드름·바디브러시 안내 — 자료 부족
- 세럼 개수 과다 경고 — 2개 이상 사용이 일반적이라 제거. 성분 중복은 540·550이 담당
- `Q-M2`(보습제 기능성)·`Q-S3`(세럼 주기) — 현재 소비 룰 없음. 제품 데이터(P2) 확보 후 연결
- 결과 카드 3장 제한 — 발동 룰이 3개를 넘을 때 무엇을 우선 노출할지는 sort_order로 제어. 실사용 데이터 확인 후 조정 필요
